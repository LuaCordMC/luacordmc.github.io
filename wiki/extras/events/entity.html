Entity events¶

This is the complete list of entity events. They cover mobs, animals, villagers, projectiles and dropped items. See the event list for how to read the table.

Event When it happens Can you cancel it?
AreaEffectCloudApplyEvent A lingering potion cloud applies its effects Yes
ArrowBodyCountChangeEvent The number of arrows stuck in an entity changes Yes
BatToggleSleepEvent A bat wakes up or falls asleep Yes
CreatureSpawnEvent A creature spawns in the world Yes
CreeperPowerEvent A creeper becomes charged or loses its charge Yes
CubeMobSplitEvent A slime or magma cube splits into smaller ones Yes
EnderDragonChangePhaseEvent The ender dragon switches to a different behavior Yes
EntityAirChangeEvent An entity's air supply changes Yes
EntityBreakDoorEvent A mob breaks down a door Yes
EntityBreedEvent Two animals breed and a baby is born Yes
EntityChangeBlockEvent A non-player entity changes a block, like an enderman picking one up Yes
EntityCombustByBlockEvent A block sets an entity on fire Yes
EntityCombustByEntityEvent An entity sets another entity on fire Yes
EntityCombustEvent An entity catches fire Yes
EntityCreatePortalEvent An entity creates a portal Yes
EntityDamageByBlockEvent An entity is hurt by a block Yes
EntityDamageByEntityEvent An entity is hurt by another entity Yes
EntityDamageEvent An entity takes damage Yes
EntityDeathEvent A living entity dies No
EntityDismountEvent An entity gets off a vehicle or another entity Yes
EntityDropItemEvent An entity drops an item, like a chicken laying an egg Yes
EntityEnterBlockEvent An entity goes into a block, like a bee into a hive Yes
EntityEnterLoveModeEvent An animal enters love mode, ready to breed Yes
EntityExhaustionEvent A player's exhaustion, which drains hunger, changes Yes
EntityExplodeEvent An entity, like a creeper or TNT, explodes Yes
EntityInteractEvent A non-player entity interacts with something, like stepping on a pressure plate Yes
EntityKnockbackByEntityEvent An entity is knocked back by another entity Yes
EntityKnockbackEvent A living entity is knocked back Yes
EntityMountEvent An entity gets onto a vehicle or another entity Yes
EntityPickupItemEvent An entity picks up an item Yes
EntityPlaceEvent A player places an entity, like a boat or an armor stand Yes
EntityPortalEnterEvent An entity touches a portal No
EntityPortalEvent An entity goes through a portal to another world Yes
EntityPortalExitEvent An entity comes out of a portal Yes
EntityPoseChangeEvent An entity changes pose, like crouching or swimming No
EntityPotionEffectEvent An entity gains, loses or changes a potion effect Yes
EntityRegainHealthEvent An entity heals Yes
EntityRemoveEvent An entity is removed from the world No
EntityResurrectEvent An entity is about to be saved by a totem of undying Yes
EntityShootBowEvent An entity shoots a bow Yes
EntitySpawnEvent Any entity spawns Yes
EntitySpellCastEvent A mob casts a spell Yes
EntityTameEvent An entity is tamed Yes
EntityTargetBlockEvent A mob targets a block Yes
EntityTargetEvent A mob targets or stops targeting something Yes
EntityTargetLivingEntityEvent A mob targets or stops targeting a living entity Yes
EntityTeleportEvent An entity teleports Yes
EntityToggleGlideEvent An entity starts or stops gliding with an elytra Yes
EntityToggleSwimEvent An entity starts or stops swimming Yes
EntityTransformEvent An entity turns into another kind, like a villager becoming a zombie villager Yes
EntityUnleashEvent An entity is let go from a leash No
ExpBottleEvent A bottle o' enchanting breaks Yes
ExplosionPrimeEvent An entity is about to explode Yes
FireworkExplodeEvent A firework explodes Yes
FoodLevelChangeEvent An entity's hunger level changes Yes
HorseJumpEvent A horse jumps Yes
ItemDespawnEvent A dropped item disappears after sitting too long Yes
ItemMergeEvent Two dropped items merge into one stack Yes
ItemSpawnEvent An item appears in the world Yes
LingeringPotionSplashEvent A lingering potion lands Yes
PigZapEvent A pig is struck by lightning and turns into a zombified piglin Yes
PigZombieAngerEvent A zombified piglin becomes angry Yes
PiglinBarterEvent A piglin trades with a player Yes
PlayerDeathEvent A player dies. This one is about players, but it lives in the entity package. No
PlayerLeashEntityEvent A player puts a leash on an entity Yes
PotionSplashEvent A splash potion lands Yes
ProjectileHitEvent A projectile hits something Yes
ProjectileLaunchEvent A projectile is shot or thrown Yes
SheepDyeWoolEvent A sheep gets dyed Yes
SheepRegrowWoolEvent A sheep grows its wool back Yes
SpawnerSpawnEvent A spawner makes a mob Yes
StriderTemperatureChangeEvent A strider gets cold or warms up Yes
TrialSpawnerSpawnEvent A trial spawner makes a mob Yes
VillagerAcquireTradeEvent A villager gets a new trade Yes
VillagerCareerChangeEvent A villager changes job Yes
VillagerReplenishTradeEvent A villager restocks a trade Yes
VillagerReputationChangeEvent A villager's opinion of a player changes Yes
